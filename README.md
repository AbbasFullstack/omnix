## ⚙️ Setup

1. Repo clone karein
2. `pnpm install`
3. Environment variables add karein (neeche dekhein)
4. Supabase mein `chats` + `memory` tables ki SQL run karein
5. `pnpm dev` → http://localhost:3000

---

## 🔑 Environment Variables

`.env.local` mein yeh variables chahiye (values apni keys se bharein):

```
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
OPENROUTER_API_KEY
HF_TOKEN
GITHUB_CLIENT_ID
GITHUB_CLIENT_SECRET
```

---

## 🚀 Run Locally

```bash
pnpm install
pnpm dev
```
